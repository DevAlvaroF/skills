# Promptly

A hand-written stand-in for a TurboStarter AI kit repo with Core's organizations and billing ported in: a web app
(`apps/web`), a mobile app (`apps/mobile`), shared packages under `packages/`. No TurboStarter code is copied here;
names and paths follow the kit's layout so the skills can find their way. Dependencies are not installed, so neither
app builds or runs; `npm test` runs the API tests under `test/` with `node:test`.
