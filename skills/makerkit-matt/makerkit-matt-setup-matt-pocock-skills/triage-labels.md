# Triage Labels

The skills speak in terms of seven canonical workflow state roles. This file maps those roles to the actual label strings used in this repo's issue tracker.

| State in these skills                    | State in our tracker                    | Meaning                                                            |
| ---------------------------------------- | --------------------------------------- | ------------------------------------------------------------------ |
| `needs-triage`                           | `needs-triage`                          | Maintainer needs to evaluate this issue                            |
| `needs-info`                             | `needs-info`                            | Waiting on reporter for more information                           |
| `ready-for-agent`                        | `ready-for-agent`                       | Fully specified, ready for an AFK agent                            |
| `ready-for-human`                        | `ready-for-human`                       | Requires human implementation                                      |
| `done-coding-awaiting-final-review`      | `done-coding-awaiting-final-review`     | Coding and implementing-agent review done; awaiting final review   |
| `done-final-review`                      | `done-final-review`                     | Independent final review complete; no coding changes remain        |
| `wontfix`                                | `wontfix`                               | Will not be actioned                                               |

When a skill mentions a role or workflow state, use the corresponding tracker string from this table.

Edit the right-hand column to match whatever vocabulary you actually use.
